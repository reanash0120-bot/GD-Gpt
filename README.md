# GD GPT v1.00

A Geode mod foundation for an AI-assisted Geometry Dash editor.

## Current milestone

- GD GPT editor button
- Basic GD-style assistant panel
- Mobile-conscious UI sizing
- Foundation for future AI command/build systems

## Planned systems

AI chat, smart questions, intent preview, object/trigger generation,
gameplay generation, block design, layers, particles, portal/orb gimmicks,
start positions, playtesting, reporting, and universal level showcase.

## Build

Use a Geode development environment with the SDK configured through
the `GEODE_SDK` environment variable, then configure/build this project
with CMake.

The exact Geode/GD compatibility values should be checked against the
SDK and game build installed on the development machine before release.
